## Project Title: Task Webb Application

## Description

This project demonstrates my understanding of the Vanilla Stack — HTML, CSS, and JavaScript without relying on external frameworks or libraries. It is a fully functional task management web application that allows users to:

- Add new tasks
- View and filter tasks by status (pending or completed)
- Edit and delete tasks dynamically
- Mark tasks as completed for progress tracking.
- Reorganize tasks using intuitive drag‑and‑drop functionality
- Persist data by saving tasks to local storage

Through this project, I focused on building a clean, accessible, and interactive user experience while reinforcing core web development principles.
